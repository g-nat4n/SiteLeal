# Leal Administradora de Condomínios

Site institucional da Leal, feito com a mesma base do site do hospital: Next.js, React, TypeScript e Tailwind CSS.

## Páginas

- Home
- Empresa
- Serviços, com o detalhe de cada área
- Legislação
- Contato, com telefones, e-mails, endereço e mapa
- Acessos on-line do CondPrime: Condômino, Gestão e Portaria

## Como rodar

```bash
npm install
npm run dev
```

O formulário de contato envia e-mail quando as variáveis do arquivo `.env.example` estão preenchidas. Sem SMTP, o botão abre o programa de e-mail do visitante.
